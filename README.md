# Vista Studios — site

Site estático (HTML, imagens e fonte). Para publicar no GitHub Pages:

1. Suba todos estes arquivos na raiz de um repositório.
2. No repositório: Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `(root)` → Save.
3. Em alguns minutos o site fica no ar em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
